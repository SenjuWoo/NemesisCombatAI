# Security policy

## Supported versions

Only the latest release is supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Do not post details in a public issue.

The plugin makes no network connections and reads only its own INI files from `Data/SKSE/Plugins/NemesisCombatAI.d`. Crashes and gameplay bugs are not security issues; open a normal issue and attach `NemesisCombatAI.log` and `skse64.log` from `Documents/My Games/Skyrim Special Edition/SKSE`.
