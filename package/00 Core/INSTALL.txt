Nemesis Combat AI 3.0.8

Gives enemies a brain: nerve, morale and tactics that depend on who they are and what is happening around them.
Movesets, attacks and animations are NOT touched: For Honor In Skyrim BFCO owns movesets, NPC Spell Variance owns
spells, NFF owns follower commands.

REQUIREMENTS
  Hard:     SKSE64 for your game build, and the Address Library for SKSE Plugins that matches that exact build.
            Runtime-confirmed by the author: Skyrim AE 1.6.1170 with SKSE 2.2.8 (loads, initialises, reads a save,
            grades casters). DECLARED but NOT yet runtime-tested: 1.6.629-1.6.1179, 1.7.99 and 1.7.104 - the version
            block advertises those builds and the code has no build-specific paths, but that is a declaration, not a
            test. If one of them refuses to start, report the build and the log instead of assuming it should work.
            Address Library: 1.6.x needs v11, 1.7.99/1.7.104 need All-in-One v13 or newer (it adds
            versionlib-1-7-104-0.bin). Skyrim SE 1.5.97 is NOT supported: the plugin refuses to load on it instead of
            writing engine fields at the older layout's offsets. No Visual C++ redistributable is needed: the runtime
            is linked statically. VR is not supported.
  For the tiered combat styles: SkyPatcher.   For the in-game menu: SkyUI + MCM Helper.
  Optional: Dynamic Grip, For Honor In Skyrim BFCO (both detected automatically), KID (only tags weapons and
            armor with keywords that other mods may use; Nemesis itself no longer needs it).

INSTALL / UPDATE
  Install the archive with your mod manager. The installer detects what you have and tells you on its last
  page (ticked and locked = found, greyed out = not installed). Replace 2.x; do not mix old and new files.
  If you used 2.x's "For Honor Hero Gate" overlay, remove it: 3.0 no longer ships it, For Honor chooses its own
  weapon masters. Delete the old NemesisCombatAI_DynamicGrip_DISTR.ini if a manual install left it behind.
  Disable "SkyTactics - Dynamic Combat Styles.esp": the tiered styles here replace it.

WHAT IT DOES
  Nerve and morale (always): every enemy in combat has a mind rating from its level, combat skill, faction rank,
  leader title and faction doctrine. Untrained fighters break and run only when their pack does: their leader
  falls, or they are losing the crowd and still have someone fighting beside them. A lone survivor never runs, and
  a high-level player, low health or being outnumbered do not make anyone run on their own (vanilla bandits are
  Foolhardy or Brave and fight on, and so they do here). Trained soldiers hold; veterans turn desperate instead of
  breaking; elites stay composed. Only the engine's own Confidence value moves, and it is put back a few seconds
  after the moment passes and when the fight ends. Fleeing=never in the settings switches running off completely.
  Tiered combat styles ("Full tactics" option): 31 styles for human melee, Draugr, archers, Forsworn, bosses and
  mages. Mages are graded by their own level, from untrained casters that stand and bolt to archmages that kite.
  For Honor wins: NPCs that For Honor picks as weapon masters are treated as Elite and, when Dynamic Grip is
  installed, kept out of Dynamic Grip so their For Honor movesets are not replaced.
  Dynamic Grip option: only Trained-or-better fighters (never casters) switch grips in combat.
  Animals, followers, teammates, essential actors and named uniques are skipped by default (MCM toggles).

SETTINGS
  In game: Mod Configuration Menu > Nemesis Combat AI.
  Files: Data/SKSE/Plugins/NemesisCombatAI.d/*.ini  (Fleeing=never/rare/often, CasterTiers=0/1, GripTiers=0/1, Debug=0/1, and
  CasterStyle=Plugin.esp|HexFormID to grade another mod's caster style). Later file names win; add your own file
  instead of editing the shipped ones. Debug=1 writes every verdict and release to the log instead of the first 25.
  A key the plugin does not know is reported in the log.

UPDATING FROM 3.0.0 - 3.0.2
  Those builds moved Confidence through the wrong engine channel (a temporary damage value, always with the sign
  stripped), so a bonus could read as a penalty. 3.0.3 applies a proper signed permanent change.
  Save records from those builds cannot be replayed safely, so outstanding records are dropped on load with one line
  in the log. An actor that was mid-fight when such a save was made can keep a small Confidence offset until it
  respawns; nothing else in the save is affected. New saves use co-save version 2.

UNINSTALL
  Make your last save while no enemy is fighting you, then disable the mod. Combat styles and keywords are applied
  in memory each session and are never in your save. The one thing a save can hold is the Confidence shift of
  enemies that were mid-fight when you saved: the plugin takes it back the next time that save is loaded, so it
  has to be installed for that load. If you already removed the mod, those few enemies keep a Confidence offset of
  at most 2.5 until they die or respawn; nothing else is affected.

TROUBLESHOOTING
  Log: Documents\My Games\Skyrim Special Edition\SKSE\NemesisCombatAI.log. It shows the version and game build,
  settings read, integrations found, how many casters were graded, and the first verdicts of a session. When
  reporting a problem, include that file and your SKSE log (skse64.log).
  "Skyrim 1.5.97 uses the pre-1.6.629 structure layout" in the log: you are on Skyrim SE 1.5.97, which this build
  does not support. Update to AE 1.6.629 or newer, or stay on Nemesis Combat AI 2.0.4.
  Game appears to hang at startup with no window: check for a small "Cache Recursive Directory Walk" dialog asking
  whether to regenerate CRDW cache files. Answer No unless you just changed files in Data. The dialog sits behind the game
  window and blocks loading until it is answered. This is CRDW's own prompt, not this mod.
  "REL/ID.h(...): failed to open address library file" or "Unsupported address library format" from this DLL means
  your Address Library does not match your game build; update it (v13 or newer for 1.7.99/1.7.104). 3.0.1 is built to
  fix the version of this error that 3.0.0 threw on 1.7.104; confirmation on 1.7.x is still pending.

TESTING STATUS
  Built from source, host-tested and tool-validated. 3.0.7 was started on Skyrim AE 1.6.1170 with SKSE 2.2.8 and a
  333-plugin load order: it loaded, read its settings, found For Honor and Dynamic Grip, graded casters, went through
  a save load and excluded a For Honor master from Dynamic Grip, with no error line and no crash. 3.0.8 changes only
  when an enemy may run away; its rules are covered by host tests (including a sweep of 233,280 fighter/fight
  combinations) but it has not been started in the game. Gameplay was last played on 3.0.0.
  Still open: the Confidence value has not been read back in a played fight since 3.0.0, and no run on 1.7.99 or
  1.7.104 exists (those builds are declared, not tested). Long sessions, huge battles and every mod combination are
  untested. Keep the previous version's archive so you can go back, and report anything odd with the two logs.

IF THE GAME CRASHES
  Send NemesisCombatAI.log, skse64.log and the crash log (CrashLogger or Trainwreck). From 3.0.7 a C++ error inside
  this plugin is written to NemesisCombatAI.log as "<where>: <message>" instead of closing the game, and a log file
  that cannot be created (protected or unusual Documents folder) no longer stops the plugin.
