# What this mod touches, and what it never does

**Never:** starts combat, forces animations, adds factions, disables AI, hooks game functions, runs per-frame work, edits attacks, perks, packages, OAR/BFCO/For Honor files, parry rules or animation variables.

**Per-actor, at runtime (native plugin):**
- Shifts the engine's own **Confidence** value (a permanent modifier measured against the authored value, so fear and rally effects stay on top untouched) by a tracked amount while an enemy is in combat, and takes exactly that amount off again when combat ends, the actor dies or unloads, or the MCM master toggle goes off. The result is clamped to the engine's 0..4 scale.
- **Enemies are not made to run by ordinary pressure.** With the default `Fleeing=rare`, Confidence is lowered only when a pack of untrained fighters is breaking (their leader fell, or they are losing the crowd and still have someone fighting beside them), and then no lower than Average, which only avoids higher-level opponents. A lone survivor never runs, trained soldiers, veterans, elites, leaders, the fearless and For Honor masters never rout, and a high-level player, low health or being outnumbered cannot lower it by themselves. The lowered value is given back a few seconds after the pack stops breaking. `Fleeing=never` switches lowering off entirely; `Fleeing=often` allows milder pressure to shake untrained fighters too.
- An amount still outstanding at save time is stored in the SKSE co-save (record `NMSI`, version 2), so a save made mid-fight is cleaned on load. Version 1 records from 3.0.0-3.0.2 are dropped with one log line because those builds applied the amount differently.
- Skipped by default: followers and teammates, essential actors, named uniques, anyone not hostile to the player, children, and **animals** (wolves, bears and the like keep their own nerve). Creatures (Falmer, giants, spriggans and the like) are never routed, and the undead (not vampires), daedra and Dwarven constructs are treated as fearless from their race data, whatever faction they belong to.
- If For Honor is installed, any NPC it marks as a weapon master (its perk, ForHonorBFCO.esp `0xD7B`) is treated as Elite. If Dynamic Grip is also installed, that NPC's base is given Dynamic Grip's own blacklist keyword (DynamicGrip.esp `0x815`, editor ID `DynamicGrip_BlacklistKwd`) so Dynamic Grip leaves its For Honor moveset alone. Only people are touched, never the player, and only keywords this plugin added are ever removed. The keyword is held in memory for the session; nothing about it is written to your save.

**Once per session, at the first load (native plugin, optional):** the combat style of human-like casters on the vanilla mage styles (csHumanMagic, csWE31Mage, csWERangedConjurer, csSoldierMagic, csWarlock, csForswornMagic, csVampireMagic, csDraugrMagic) is switched to one of eight Nemesis caster styles chosen from the caster's own level and skill. Followers, named uniques (while Skip Uniques is on), template NPCs and non-people are left alone. This is the same base-record change SkyPatcher makes.

**At load time (SkyPatcher):** `NemesisCombatAI_Styles.esp.ini` swaps combat styles only for NPCs on the vanilla human melee, Draugr, archer, Forsworn and boss styles, using 23 Nemesis styles. `ZZZ_NemesisCombatAI.ini` keeps the 2.x faction style pools; it loads after the tier file, so with Full tactics the human-melee faction lines in it no longer find their targets (the tier file already restyled them) and the caster lines are superseded by the level grading. Neither file changes Aggression or Confidence.

**To undo everything:** save while no enemy is fighting you, then disable the mod. Combat styles and keywords are not saved in your game. A Confidence shift still applied to enemies at the moment you save is taken back by the plugin the next time that save is loaded, so the plugin must still be installed for that load; without it those enemies keep an offset of at most 2.5 until they die or respawn.

Built and tool-checked. Gameplay was played on 3.0.0; 3.0.3-3.0.5 and 3.0.7 were load-tested on Skyrim AE 1.6.1170 (load, save load, caster grading, For Honor exclusion); no fight was played on them, and no build has been run on 1.7.x. 3.0.8 (when an enemy may run away) and 3.0.9 (race-aware doctrine, leader rule, event filtering) are host-tested, not started in the game. Report problems with `NemesisCombatAI.log` from `Documents\My Games\Skyrim Special Edition\SKSE`.
